# IPTVPlayer LIVE APP — Интеграция на сайты

## 📋 Как встроить плеер на другой сайт

### Способ 1: iframe (Рекомендуемый)

```html
<iframe 
  src="https://your-domain.com/live/player.html" 
  width="100%" 
  height="600" 
  frameborder="0" 
  allowfullscreen 
  allow="autoplay; encrypted-media; fullscreen; picture-in-picture">
</iframe>
```

### Способ 2: Embed для конкретного канала

После загрузки плейлиста и выбора канала:
1. Нажмите кнопку 🔗 в плеере
2. Скопируйте код из модального окна
3. Вставьте на свой сайт

Пример кода для вставки:
```html
<iframe 
  src="https://your-domain.com/live/embed.html?url=https://example.com/stream.m3u8&name=Канал 1" 
  width="640" 
  height="360" 
  frameborder="0" 
  allowfullscreen>
</iframe>
```

### Способ 3: Прямая ссылка на канал

```html
<a href="https://your-domain.com/live/player.html" target="_blank">
  Открыть IPTV плеер
</a>
```

## ⚙️ Настройки движка воспроизведения

В плеере доступны 4 движка:

| Движок | Описание | Когда использовать |
|--------|----------|-------------------|
| ⚡ PlayerJS (Основной) | Проприетарный плеер с максимальной совместимостью | По умолчанию, для большинства потоков |
| 🔄 HLS.js (Fallback 1) | Open-source HLS плеер | Если PlayerJS не работает |
| 📹 Dash.js (Fallback 2) | Для DASH/MPD потоков | MPEG-DASH контент |
| 🎥 Native HTML5 | Нативный браузерный плеер | MP4, WebM, прямые ссылки |

## 🔧 Параметры URL для embed.html

| Параметр | Описание | Пример |
|----------|----------|--------|
| url | Ссылка на поток | `?url=https://.../stream.m3u8` |
| name | Название канала | `&name=Первый канал` |
| logo | Логотип канала | `&logo=https://.../logo.png` |

## 🎨 Стилизация

Все стили находятся в `/live/css/player.css`. Вы можете переопределить CSS переменные:

```css
:root {
  --accent: #e63946;      /* Акцентный цвет */
  --bg: #080c14;          /* Основной фон */
  --text: #f0f4ff;        /* Цвет текста */
}
```

## 💡 Советы по интеграции

1. **Для WordPress**: Используйте блок "HTML-код" или плагин для iframe
2. **Для Tilda**: Блок T123 (HTML-код)
3. **Для Wix**: Element → Embed Code → Embed HTML
4. **Для самописных сайтов**: Просто вставьте iframe в нужное место

## 🆘 Troubleshooting

**Проблема**: Плеер не загружается
- Проверьте HTTPS соединение
- Убедитесь, что нет блокировок CORS
- Попробуйте другой движок воспроизведения

**Проблема**: Поток не воспроизводится
- Проверьте ссылку на поток в браузере
- Попробуйте сменить движок (HLS.js → PlayerJS → Native)
- Проверьте консоль браузера на ошибки

**Проблема**: Модальное окно показывает другой плеер
- Убедитесь, что используется последняя версия player.js
- Очистите кэш браузера
- Проверьте пути к файлам (player.html, embed.html)
